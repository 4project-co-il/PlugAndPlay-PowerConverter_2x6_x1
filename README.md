# PlugAndPlay: Power Converter for Pololu's D42V55Fx and D36V50Fx voltage regulator modules
This is the repository with the files for PlugAndPlay power converter board.

The board has 2x PnP power module ports and one connector for Pololu's D42V55Fx or D36V50Fx voltage regulator module.
One PnP power module port is used as an input, another as an output and the connector allows pluging in one of the Pololu's voltage regulators from D42V55Fx or D36V50Fx families.
